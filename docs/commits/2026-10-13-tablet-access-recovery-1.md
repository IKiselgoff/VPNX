# Tablet access recovery

## Изменения
Сохранённые Android исходники 69d3826 интегрированы в актуальную main для выпуска 1.2.9. Host pins подписанного APK добавляются при переносе сохранённых credentials; ключи и remote ports сохранены. Runtime и bootstrap-секреты исключены из Git.

## Влияние
Сборка включает mirror, раздельные SSH-сессии, AlarmManager/JobScheduler recovery, Shizuku и shell-watchdogs. Ограничения no-root восстановления описаны в эксплуатации.

## Проверка
Gradle assembleDebug успешно собрал 1.2.9, подпись и версия проверены. На планшете 1.2.4 зеркало получило 25 профилей, но direct control отсутствовал. Резервный Mac затем перестал отвечать. Проверка установки 1.2.9 и доступности требует возобновления рабочего канала.
