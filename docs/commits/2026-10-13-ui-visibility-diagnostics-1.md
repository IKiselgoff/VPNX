# UI visibility diagnostics

## Изменения
Повторное открытие приложения показывает окно; собственный UI экспортируется флагом `--snapshot` для проверки layout по SSH.

## Модули
`macos-subscriptions` / Cocoa UI.

## Проверка
Сборка под macOS 10.15, визуальная проверка экспортированного окна на целевом Mac.
