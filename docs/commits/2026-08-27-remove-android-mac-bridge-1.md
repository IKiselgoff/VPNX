# Remove Android Mac bridge

## Изменения

- Удалён временный macOS LaunchAgent для ADB reverse-forward.
- На VPS отозвано разрешение ключа Mac на порт `25555`.
- Финальный диагностический endpoint оставлен только на `127.0.0.1:25556` прямого агента планшета.

## Влияние

Mac больше не участвует в удалённой диагностике Android.

## Проверки

- На VPS отсутствует listener `25555`.
- ADB shell через `25556` возвращает `NO_MAC_OK` и `SM-X205`.
