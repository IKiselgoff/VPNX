# Demote Android Mac bridge

## Изменения

- Прямой endpoint `127.0.0.1:25556` назначен основным.
- Mac-мост `127.0.0.1:25555` сохранён как резервный путь.

## Влияние

Обычная диагностика не зависит от Mac, но резервный путь остаётся доступным при отказе прямого агента.

## Проверки

- ADB shell через `25556` возвращает `NO_MAC_OK` и `SM-X205`.
