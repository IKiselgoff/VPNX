# Android HyperOS provisioning

## Изменения
- USB provisioning создаёт приватный каталог приложения перед копированием maintenance credentials.

## Влияние
Первая установка на HyperOS больше не прерывается, если приложение ещё не успело самостоятельно создать `files`.

## Проверка
- Выполнить provisioning на чистой установке VPNX.
- Проверить наличие пяти credential-файлов с правами владельца приложения.
