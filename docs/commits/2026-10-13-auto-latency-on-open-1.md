# Automatic latency on open

## Изменения
Фоновая проверка при открытии окна, сортировка быстрых рабочих профилей по умолчанию и использование свежих результатов кнопкой «Подключить лучший».

## Модули
`macos-subscriptions`, эксплуатация.

## Проверка
Сборка Catalina и regression suite; автоматическая проверка не переключает активный runtime.
