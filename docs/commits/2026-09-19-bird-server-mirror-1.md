# BIRD server mirror refresh

## Изменения
- Добавлен updater Telegram VLESS-кандидатов из локального snapshot зеркала.
- Прямых обращений к Happ-подписке нет, поэтому второй клиент не может перепривязать устройство.
- 15-минутный systemd timer проверяет Telegram SOCKS; при двух сбоях вызывает штатный selector.

## Влияние
Telegram-прокси не рестартует при обновлении списка; рабочий узел сохраняется.

## Проверка
- Выполнить updater на действующем локальном зеркале и проверить 14 профилей.
- При испорченном snapshot список кандидатов должен остаться без изменений.
- Проверить ответ Telegram через действующий SOCKS после обновления.
