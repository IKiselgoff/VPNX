# Big Sur runtime release

## Изменения
Исправлен URL legacy runtime на опубликованный Xray 26.3.27 с SHA-256 из официального digest; ранее указанный архив 26.10.10 отсутствует.

## Влияние
Воспроизводимая установка актуального доступного Xray и compatibility dylib на Intel Big Sur без замены системных framework.

## Проверка
Сборка compatibility runtime, запуск на Big Sur, проверка профилей и синхронизации зеркала при установке.
