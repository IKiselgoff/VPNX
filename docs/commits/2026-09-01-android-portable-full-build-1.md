# Android portable full build

## Изменения

- Первый запуск автоматически синхронизирует встроенную подписку BIRD.
- После синхронизации однократно открывается обязательный Android VPN consent.
- Версия Android-приложения повышена до `1.1.0` (`versionCode 2`).

## Влияние

Один APK можно безопасно ставить на новое arm64-устройство без переноса конфигурационных файлов или персональных maintenance-ключей.

## Проверки

- Загрузка актуального runtime и BIRD bootstrap.
- Android debug build.
