# Active Auto latency

## Изменения
Активный совпадающий runtime проверяется существующим движком. Холодный Auto получает короткий warm-up и повтор HTTPS; окно увеличено для новых элементов.

## Модули
`macos-subscriptions`.

## Проверка
Regression test подтверждает отсутствие запуска второго движка для активного совпадающего профиля. На Mac активный Auto давал HTTPS 204 при неуспешной холодной изолированной проверке.
