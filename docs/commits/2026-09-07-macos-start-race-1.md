# macOS start race

## Изменения
- Запуск и остановка Xray сериализованы межпроцессной блокировкой.
- Статус восстанавливает PID по фактическому процессу.
- Ошибка раннего запуска отключает системный proxy.
- Минутный watchdog восстанавливает runtime и сохраняет ручное состояние Stop.

## Модули
- `macos-vpnx`

## Проверка
- Параллельный запуск одного профиля оставляет один Xray и корректный PID.
- Watchdog восстанавливает аварийно завершённый Xray, но не ручную остановку.
- Перезапуск и proxy-запрос проверены на macOS Big Sur.
