# Latency and routing controls

## Изменения
- Реальная HTTPS-проверка профилей на изолированных SOCKS-портах с ограничением параллелизма и очисткой процессов.
- UI: задержка, сортировка, проверка группы, выбор рабочего быстрого подключения, режимы routing.
- Маршруты формируются в runtime-кандидате; Auto balancer и исходные подписки сохраняются.

## Модули
`macos-subscriptions`, эксплуатация.

## Проверка
Сборка Catalina, regression tests сохранения балансов и invalidation устаревшей задержки. Runtime recovery отдельно проверен после установки исправления launchd.
