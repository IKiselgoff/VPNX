# BIRD Happ Mac cache producer

## Изменения
- Новый локальный hourly producer использует уже сохранённую Happ идентичность Mac для исходного subscription endpoint.
- Макрос Copy URLs переведён на тот же producer и копирует валидные ссылки после обновления.
- Исправлено экранирование SSH-команды публикации JSON.

## Влияние
- VPS больше не обращается к исходной подписке; при отсутствии локальной Happ идентичности producer отказывается от запроса.
- Последний рабочий snapshot не затирается при ошибке загрузки или валидации.

## Проверка
- Запрос с Mac вернул 14 профилей; JSON опубликован на VPS, повторный запуск не меняет данные.
- `--copy-urls` скопировал 32 VLESS-ссылки.
