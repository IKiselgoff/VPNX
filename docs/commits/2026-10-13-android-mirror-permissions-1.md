# Android mirror permissions

## Изменения
Publisher назначает root:www-data и 0640 новому snapshot до атомарной замены.

## Влияние
Установленные Android используют прежний приватный HTTPS URL и снова получают актуальные профили; файл не становится общедоступным локально.

## Проверка
На VPS воспроизведён 403 с Permission denied для root:root 0600. После исправления HTTPS возвращает 200, 25 профилей и побайтное совпадение с snapshot.
