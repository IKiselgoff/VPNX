# Android VPNX bootstrap

## Изменения

- Сборка получает актуальный снимок BIRD вместе с Xray runtime.
- Приложение инициализирует локальные профили этим снимком только при отсутствии сохранённой подписки.
- Сетевые синхронизации продолжают заменять снимок после успешной проверки JSON.

## Влияние

Первое VPN-подключение больше не блокируется недоступностью endpoint подписки до запуска туннеля. Конфигурации с ключами остаются вне Git.
