# Module: macos-subscriptions

## Назначение
Управление подписками, полными Xray-профилями и видимым состоянием обновлений macOS VPNX.

## Ответственность
Реестр источников, загрузка, проверка установленным Xray, атомарная запись узлов и переключение изменившегося активного профиля. Интерфейс Cocoa выполняет команды вне UI-потока.

## Архитектурная роль
BIRD приходит с VPS через forced read-only SSH command; дополнительные подписки используют HTTPS JSON. Producer Happ на основном Mac остаётся единственным источником обновления BIRD.

## Зависимости
Системный Python 3.8+, Cocoa macOS 10.15+, Xray, launchd, OpenSSH с закреплённым host key.

Legacy runtime: официальный Xray 26.10.10 с проверенным SHA-256 архива и приватной Security dylib. Она re-export системный Security и реализует отсутствующий `SecTrustCopyCertificateChain` через Catalina API; trust evaluation не меняется.

## Структуры данных
`subscriptions.json`: id, name, kind, enabled, interval, приватный URL. `subscription-status.json`: last_attempt, last_success, snapshot_updated_at, error, profiles. Идентификатор узла зависит от имени и подписки, без фиксированного списка стран.

## Логика работы
Каждый источник проверяется раз в 15 минут; launchd проверяет наступление интервала каждые 60 секунд. Полный snapshot сначала нормализуется под локальные loopback inbounds и проходит Xray `run -test`. Только после успешной проверки всех узлов публикуются файлы и state. Неизменившийся активный профиль не перезапускается; ручная остановка сохраняется.

## Ключевые функции
- `fetch(subscription)`: получает полный snapshot и время источника; SSH ключ допускает только чтение зеркала.
- `normalize(config)`: сохраняет outbound/routing/observatory/transport; локализует журналы и входящие порты.
- `sync_one(subscription, states)`: применяет проверенный snapshot, сохраняет диагностику ошибок и последний успешный набор.
- `status()`: возвращает UI-состояние без URL и секретов; ручные профили группируются отдельно.

## Failure Modes
Отказ SSH/HTTPS или несовместимый Xray оставляет прежние профили. Дата успешного скачивания и дата самого snapshot различаются; UI предупреждает о возрасте более суток. Удаление активной подписки запрещено до переключения. JSON-подписки не являются универсальным парсером VLESS URI/base64.
