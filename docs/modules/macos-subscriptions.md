# Module: macos-subscriptions

## Назначение
Управление подписками, полными Xray-профилями и видимым состоянием обновлений macOS VPNX.

## Ответственность
Реестр источников, загрузка, проверка установленным Xray, атомарная запись узлов и переключение изменившегося активного профиля. Интерфейс Cocoa выполняет команды вне UI-потока.

## Архитектурная роль
BIRD приходит с VPS через forced read-only SSH command; дополнительные подписки используют HTTPS JSON. Producer Happ на основном Mac остаётся единственным источником обновления BIRD.

## Зависимости
Системный Python 3.8+, Cocoa macOS 10.15+, Xray, launchd, OpenSSH с закреплённым host key.

Legacy runtime: официальный Xray 26.10.10 с проверенным SHA-256 архива и приватной Security dylib. Она re-export системный Security и реализует отсутствующий `SecTrustCopyCertificateChain` через Catalina API; trust evaluation не меняется.

## Структуры данных
`subscriptions.json`: id, name, kind, enabled, interval, приватный URL. `subscription-status.json`: last_attempt, last_success, snapshot_updated_at, error, profiles. Идентификатор узла зависит от имени и подписки, без фиксированного списка стран.

`routing.json`: режим (`subscription`, `global`, `ru-direct`). `profile-latency.json`: HTTPS-результат, миллисекунды, время, режим и hash профиля; результат устаревает через час или при изменении профиля/режима.

## Логика работы
Каждый источник проверяется раз в 15 минут; launchd проверяет наступление интервала каждые 60 секунд. Полный snapshot сначала нормализуется под локальные loopback inbounds и проходит Xray `run -test`. Только после успешной проверки всех узлов публикуются файлы и state. Неизменившийся активный профиль не перезапускается; ручная остановка сохраняется.

## Ключевые функции
- `fetch(subscription)`: получает полный snapshot и время источника; SSH ключ допускает только чтение зеркала.
- `normalize(config)`: сохраняет outbound/routing/observatory/transport; локализует журналы и входящие порты.
- `sync_one(subscription, states)`: применяет проверенный snapshot, сохраняет диагностику ошибок и последний успешный набор.
- `status()`: возвращает UI-состояние без URL и секретов; ручные профили группируются отдельно.
- `probe_one(profile, mode)`: запускает изолированный Xray на случайном loopback SOCKS-порту, измеряет HTTPS YouTube и завершает тестовый процесс; активный профиль не переключается.
- `routed(config, mode)`: формирует runtime-маршруты без изменения исходного snapshot; сохраняет terminal balancer Auto-профилей.
- `probe(tags)` / `best`: до трёх параллельных проверок; fastest подключает только профиль с успешным свежим HTTPS-результатом.

## Failure Modes
Отказ SSH/HTTPS или несовместимый Xray оставляет прежние профили. Дата успешного скачивания и дата самого snapshot различаются; UI предупреждает о возрасте более суток. Удаление активной подписки запрещено до переключения. JSON-подписки не являются универсальным парсером VLESS URI/base64.

LaunchAgent командных обёрток требует `AbandonProcessGroup=true`: иначе launchd завершает Xray после выхода краткоживущего watchdog/sync/UI. `nohup` не защищает дочерний процесс от этого поведения launchd.

## Recent Changes
### 2026-10-21 — Big Sur runtime release
Legacy runtime builder закреплён на реально опубликованном Xray 26.3.27 и официальном SHA-256. Сборка compatibility dylib и официальный архив обеспечивают запуск на Intel Big Sur; зеркало доступно отдельным restricted read-only ключом для каждого Mac.


### 2026-10-13 — automatic latency on open
Каждое открытие окна запускает фоновую проверку профилей без отключения управления VPN; перекрывающиеся открытия не создают параллельных проверок. Рабочие быстрые профили сортируются первыми. «Подключить лучший» использует полностью свежий hash-validated результат группы до пяти минут, не заставляя повторять только что завершённую проверку.

### 2026-10-13 — latency and routing controls
HTTPS-задержка выбранного профиля или группы, сортировка, выбор быстрого рабочего подключения и три режима системного прокси. Измерение не является ICMP ping и относится к проверяемому HTTPS-сервису.

### 2026-10-13 — active Auto latency
Если active runtime совпадает с тестируемым профилем и режимом, задержка измеряется через существующий движок. Изолированные Auto-профили получают время начальной observatory-проверки и повтор HTTPS-запроса, чтобы холодный балансировщик не давал ложный отказ с первой попытки.
### 2026-10-13 — subscription manager UI
Окно с поиском, фильтром подписок, протоколами, датами, обновлением, подключением и интернет-диагностикой. Клиент больше не имитирует Happ и не запрашивает старый BIRD endpoint.

### 2026-10-13 — runtime candidate extension
Промежуточный проверяемый конфиг сохраняет `.json`, необходимый для определения формата Xray CLI.

### 2026-10-13 — UI visibility diagnostics
Повторное открытие app показывает главное окно; `--snapshot` экспортирует собственный NSView в `~/.vpnx/ui-preview.png` для визуальной проверки без screen-recording доступа.

### 2026-10-13 — launchd engine lifetime
Агенты сохраняют дочерний Xray после завершения команды запуска.
