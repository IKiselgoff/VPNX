# Module: macos-vpnx

## Назначение
Управляет локальным Xray runtime и системными HTTP/SOCKS proxy macOS.

## Ответственность
Материализует выбранный профиль, запускает один экземпляр Xray, синхронизирует PID-файл и включает либо отключает proxy для сетевых служб.

## Архитектурная роль
Исполняющий слой между BIRD snapshot, menu bar приложением и Xray.

## Зависимости
Xray, `networksetup`, `launchd`, системные shell utilities macOS.

## Структуры данных
Текущий тег хранится в `~/.vpnx/current.tag`, PID в `~/.vpnx/xray.pid`, runtime config в `~/.vpnx/config.json`.

## Логика работы
Запуск сериализуется файловой блокировкой. Уже работающий профиль переиспользуется, а смена профиля останавливает фактический процесс перед запуском нового. PID определяется также по точной командной строке Xray, поэтому устаревший PID-файл восстанавливается. Минутный launchd watchdog поднимает упавший runtime; ручной `stop` создаёт persistent-флаг `~/.vpnx/disabled`, а `start` снимает его.

## Ключевые функции
- `start`: атомарно запускает или переиспользует Xray и включает proxy.
- `stop`: завершает все экземпляры конкретного VPNX runtime и отключает proxy.
- `status`: сверяет состояние с фактическим процессом и восстанавливает PID-файл.
- `watchdog`: восстанавливает runtime, если пользователь не остановил VPN вручную.

## Failure Modes
Если Xray завершается в первую секунду, proxy отключается, а CLI возвращает ошибку и путь к журналу. Живой lock другого процесса ожидается до пяти секунд; lock погибшего процесса удаляется.
