# Data Model

- `nodes/<TAG>.json`: полный Xray config для BIRD либо legacy outbound для ручного импорта.
- `bird-subscription-state.json`: URL источника, количество профилей и отображаемое имя Happ для каждого стабильного тега.
- `current.tag`: выбранный профиль.
- `config.json`: runtime config текущего запуска Xray.
