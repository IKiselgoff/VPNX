# VPNX for Android

Нативный BIRD VPN-клиент для Android 8+.

## Возможности

- полный JSON snapshot подписки Happ BIRD;
- официальный libXray/Xray-core;
- Android `VpnService` и прямой Xray TUN;
- выбор профиля с исходными названиями Happ;
- синхронизация при запуске, каждые 15 минут и после возвращения сети;
- автозапуск ранее активного VPN после перезагрузки;
- первичная синхронизация и автоматический запрос обязательного Android VPN-разрешения при первом запуске;
- автономная регистрация нового устройства на VPS без USB, ADB и локального provisioning;
- встроенная проверка внешнего IP и Telegram.

## Сборка

```bash
./scripts/download-runtime.sh
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

При первом запуске APK самостоятельно создаёт индивидуальный RSA-ключ и control-токен, получает у VPS уникальные reverse-forward порты и поднимает защищённый maintenance-канал. Встроенный bootstrap-ключ ограничен сервером единственной командой регистрации: через него нельзя открыть shell или создать port forwarding.

USB-скрипт остаётся резервным способом подготовки телефона:

```bash
VPNX_ADB_PORT=25566 VPNX_CONTROL_PORT=25567 ./scripts/provision-device.sh
```

Скрипт требует один авторизованный по USB Android, локальные `adb`/OpenSSH и SSH-доступ к VPS.

`libXray.aar`, `geoip.dat`, `geosite.dat` и актуальный bootstrap-снимок BIRD скачиваются воспроизводимым скриптом и не хранятся в Git. Встроенный снимок используется только для первого запуска и заменяется после успешной сетевой синхронизации.

После установки требуется один раз открыть VPNX и подтвердить системные диалоги исключения из оптимизации батареи и создания VPN. Приложение не может выдать эти разрешения самостоятельно без нарушения модели безопасности Android.
